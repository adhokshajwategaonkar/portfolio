How I work

Three things I'm actually
good at.

01 — Ambiguity

Specs for things nobody
has built before

Fallback logic across four LLM providers. Tenant isolation boundaries for an agent orchestrator. A cost attribution model mapping inference spend down to the workflow. These don't have reference implementations — you write the requirement by deciding what failure is acceptable.

02 — Interfaces

Progressive disclosure over
non-deterministic systems

I prototyped Beacon's streaming agent chat from scratch: what surfaces in real time, and how a user expands from an answer into the reasoning behind it and then into the raw tool calls. Layered control, so trust is something the user can go and verify.

03 — Shipping

I build the thing, not just
the deck about the thing

Animus and Shastra are mine end to end — schema, prompts, spend caps, design language, landing page, deploy. It makes me a materially better PM: I've had to make the tradeoffs I'd otherwise be asking someone else to make.
